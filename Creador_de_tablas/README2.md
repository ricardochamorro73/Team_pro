Para usar el programa se requiere de 2 librerias: Pandas y Tabulate

Tambien python obviamente.

Estos codigos se deben poner en la terminal de tu equipo.

Para instalar tabulate y pandas prueba con:
- python -m pip install pandas tabulate
- Si no te deja prueba con: python3 -m pip install pandas tabulate

Para usar el programa ejecuten el codigo de main.py

Si todavia no te deja pues dimelo xd
